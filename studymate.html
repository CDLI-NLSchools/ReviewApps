StudyMate Practice Packs

Printable practice packs for the CDLI Review Apps. One pack covers one unit, in full: a prerequisite check with repair sets first, then a section for every indicator in the unit, mixed sets that bring earlier work back, and a unit review composed the way the unit test is composed.

How a pack works

Work on paper, in order. Every set in a pack carries a six-character code at its top. To check a set online, open the Review Apps home page, type the code into the pack code box, and the exact set opens, question for question. At home, the QR code beside the set code does the same job with a phone or tablet camera. Answer keys are at the back of every pack.

In the practice sets, questions whose answer is a value or an expression print without their answer choices, on purpose: work each one out in full, then find your answer among the choices when you check online. The unit review prints every choice, the way the test does.
