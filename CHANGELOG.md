### Changed

- If you leave an online practice set partway through, the app now saves the set itself on your device, not just your answers. When you come back to the app on the same device, a banner offers you that same set again, with any answers you entered still in place, even if the set was dealt at random and could never be drawn the same way twice. Nothing is put back until you choose Resume; Start fresh clears the saved set instead. Saved sets are kept for seven days. If a question in a saved set has been removed from the bank since, the saved set is cleared quietly instead of being offered.
- Practice sets, practice sheets and practice tests now always include at least one question on every indicator or outcome you selected, as long as the question bank holds questions for it. Before, the questions were drawn across the whole selection by level, so a set could leave one of your selected indicators out entirely by chance. Now one question on each selected indicator is set aside first and the rest of the set is drawn around those, so the size of the set, the mix of question types and the spread of difficulty levels work as before. An indicator with no questions in the bank yet is simply left out, as before.
- Practice tests in the nine science apps are sized to fit a class period, and every one of them now deals its full planned size. The multiple choice section runs to at most 18 questions: a test covering two outcomes runs 22 marks in total, three outcomes 27 marks, and four or more outcomes 30 marks. Tests covering a single outcome, which used to run 14 marks, now run a full 22 marks, with 10 multiple choice questions and a 12 mark written section. 78 new question templates across Science 7, Science 8, Science 9 and Sciences 7, 8 and 9 deepen the banks behind these tests, so no practice test needs its short heads-up any more.
- The practice builder is reorganized into three sections, so the counts for each kind of set sit with the button that builds it. Practice online comes first and now has its own two counts, Multiple choice and Fill-in: an online set deals exactly the mix you ask for, and if the units you picked do not hold enough fill-in questions, the set says so plainly instead of quietly dealing more multiple choice. The online section can also be aimed at a test: pick a unit and one of its tests, a single unit on its own, or a mid-course or final scope, and the set draws only on that scope, while the units and indicators you picked at the top stay exactly as they were for the other sections. Build a Practice Test comes next, holding the test selector, its plan summary with the More multiple choice and More written steppers, and the Make a practice exam button; choosing a test composes the paper and brings it into view. Build a Practice Sheet comes last, with the Multiple choice and Constructed Response counts, the print choices and the Make a practice sheet button. The Dual-form questions setting moves to the bottom of the builder, where it also works as a select all on a composed practice exam: switch answer choices off and every dual-form question on the paper moves into the written section at once, switch them back on and they all return. The setting itself and every link you have already shared work exactly as before.
- Practice tests in the nine science apps (Science 7, 8 and 9, Sciences 7, 8 and 9, Science 1206, Chemistry 2202 and Chemistry 3202) now carry more questions. A test is sized by the outcomes it covers: about five multiple choice questions per outcome, up to 24, and a written section of 12 marks on every test. Most practice tests now run 22 to 36 marks, where they ran 14 to 24 marks before. Tests covering a single outcome are unchanged, at 14 marks. On some tests an outcome's question bank is still thin, so those tests deal a few marks under the planned size and the paper shows its "short" heads-up, as before.
- Setting up a practice sheet or test is quicker. The Multiple choice and Constructed Response counts and the Dual-form questions setting now sit right under the units and indicators you pick, instead of at the bottom of the print panel; the print panel keeps the answer key, set code and working space choices. In the science apps, choosing a single test now shows what that test's plan composes: how many multiple choice questions, how many written questions and marks, and the total. Two controls beside it, More multiple choice and More written, add more questions from the same test's outcomes when you want a longer paper. With both at zero the paper is exactly the planned test, and the totals on the paper include whatever you add.
- In the teacher editing panel on a practice exam you compose yourself, a dual-form question can now be moved between the two sections. A question that can be asked either way carries a "Choices off" button: click it and the question moves to the written section with its choices removed, at its written mark value. A moved question carries a "Choices on" button that moves it back to the multiple choice section as the same question, worth one mark. The section totals and the paper total update at once, and the arrangement is saved with the set, so a link you copy for students and the printed paper show each question exactly where you put it. Papers built to a single test's plan, and single-unit tests, do not show the button: their plans settle which questions are written.
- Multiple choice options are now lettered on practice sheets and in online practice, the way they already were on practice tests and practice exams. Each option carries its letter (A, B, C, D) beside it, so a teacher can refer to "option B" and every student is looking at the same choice; before, options on a sheet were marked with a plain circle and online options carried no letter at all. A practice sheet's answer key now names the letter of the correct option beside the answer text as well. Word downloads and copies for Google Docs show the same letters.
- Two fixes in the test builder. The same question template can no longer appear twice on one unit test, once among the multiple choice questions and again among the written questions. And a unit test that deals exactly the questions its blueprint calls for no longer shows the "short" heads-up; Biology 2201's unit tests were showing it on every paper even though each one dealt its full 25 questions.
- Five Chemistry 2202 questions were revised after specialist review. The acid-formula question no longer deals acetic acid, whose formula broke the naming pattern the question teaches; a limestone calculation's worked solution now shows each unit conversion step; two questions name their compounds directly and ask more plainly; and the question about a student's drawing of an ionic solid now shows the drawing.
- Three small fixes on every course page. The "Include prior knowledge questions" switch in the practice builder now shows its checkbox beside its label, in one row, instead of stacked above it. The course header has more room in it: the course title sits further from the CDLI logo above it and from the "All courses" button below it, so the button no longer crowds the title. And pressing Start on a course page before choosing anything now opens the practice builder where you are, without sliding the page down, so you can see the units and the number of questions you are about to practise and change them first. Start on a page opened from a shared link still goes straight to the questions, as before.
- A spacing and readability pass across every app. Questions in an online practice set are now separated by a ruled line, with more room above and below each question; answer options sit a little further apart; headings and the score line are larger; and the "All courses" link at the top of each course home is now an outlined button. Printed sheets and tests are unchanged.
- Single-test practice sets in the science apps are now sized by the number of outcomes the test covers: about three selected-response questions per outcome, and a written section of 6 to 10 marks. A practice test now runs 14 to 24 marks and reads like the real test it rehearses, instead of being scaled down to the test's share of the whole unit test. A test covering a single outcome deals to 14 marks.
- Function graphs in Math 2200, Math 3200 and Math 3201 now end where the curve leaves the grid, instead of running flat along the top or bottom edge. - Sets built for a single unit test are now called a "Practice Test" in the builder and in downloaded file names, in English and in French. "Practice Exam" is now used only for the mid-course and final sets, so the name a set carries always says which kind of set it is.
- Prior knowledge questions no longer slip into ordinary practice. A switch labelled "Include prior knowledge questions" now sits in the practice builder, beside the unit and indicator pickers: it starts off, and it appears only when the units you picked carry prior knowledge questions. Leave it off and practice sets and practice sheets draw from the course material only; turn it on when a set should reach back to earlier material. - The set code block on a printed practice sheet or exam now sits at the very top right of the first page, with the header, the name and date lines, the title and the first questions flowing around it, instead of sitting under the name line. - Typing a set code on the home page now opens that set as online practice, for every kind of code: a pack code, a code from a set a teacher printed, or a code from a seed-built set. Before, codes from printed sets opened the print view instead. Scanning the QR code on a printed set opens the practice view too.
- Behind the scenes, typed set codes now resolve against a published snapshot of the code registry that refreshes every few minutes, instead of reading the registry sheet on every lookup. A code printed seconds earlier still resolves, because the sheet is checked whenever the snapshot does not have the code yet.
- The set code box now lives on the Review Apps home page. A student with a printed set can type the six-character code from the top of the set to open that exact set in the app, the same questions in the same order.
