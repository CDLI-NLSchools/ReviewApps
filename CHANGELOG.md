# Changelog

All notable changes to the CDLI Review Apps are listed here, newest first. The notes are written for teachers and students who use the apps.

## Unreleased

### Added

- The Review Apps home page now has a language toggle beside the dark mode toggle. Everything on the home page, including the set code box and the About card, shows in one language at a time, English or French, and the choice is remembered on the device. A first visit follows the browser's language. Pages inside a course keep the language of that course, as before.
- StudyMate practice packs. A pack is a printable PDF for one unit: a prerequisite check with revisit sets, practice for every indicator in the unit, mixed sets that bring earlier work back, and a unit review in the shape of the unit test. Math 2201 Unit 1 (Acute Triangle Trigonometry) is the first pack.
- The Math 2201 Unit 1 pack now comes in pieces as well as whole: a one-page index listing every set and its code, a separate PDF for each set with questions only, and a separate answer keys PDF for teachers, alongside the full pack. A teacher can share just the index page, on paper or digitally, and students open each set online with its code.
- Teachers can put a set code on their own printed sets. The print panel has an "Include set code and QR" option, on by default: a printed practice sheet or exam then carries a six-character code and a QR code at the top right of its first page. A student types the code into the code box on the Review Apps home page, or scans the QR code, to open that exact set.
- Saved files are named for their set: the course, whether it is a practice sheet, a unit test or an exam, the units it covers, and its set code when it has one. That name is used for Word downloads and is the suggested name when you save a print as a PDF.

### Changed

- The set code block on a printed practice sheet or exam now sits at the very top right of the first page, with the header, the name and date lines, the title and the first questions flowing around it, instead of sitting under the name line. Its QR code prints larger than before, so a phone can scan it reliably even on a long exam, where the code carries the whole set.
- The set code box now lives on the Review Apps home page. A student with a printed set can type the six-character code from the top of the set to open that exact set in the app, the same questions in the same order. The StudyMate page now sends you to the home page, where the box lives. Codes printed on the Math 2201 Unit 1 pack keep working exactly as before.
- Printed practice sheets and exams now keep a section heading with the first question of its section, so a heading never sits alone at the bottom of a page. Questions already printed whole on one page, with diagrams at the left margin and no answer line after multiple choice choices.
- The seed word note in the builder now says plainly that students never type the seed word; it only shapes the link the teacher copies.

- The Math 2201 Unit 1 question bank grew by 89 question templates: diagram questions for Indicator 7.1 (including its first harder questions), more problem types for Indicators 7.2 and 7.3, and a deeper bench of prerequisite questions. The Unit 1 pack was regenerated from the enlarged bank: no question template appears more than twice in the pack, and most questions are the first appearance of their template. The sets, their codes and the pack's shape are unchanged.
- The Math 2201 Unit 2 question bank grew by 60 question templates: new question types for every Unit 2 indicator, including reading domain, range, intercepts and vertices from graphs, building equations from graphs, tables and intercepts, matching a function to its graph, and optimization problems in new contexts, plus a deeper bench of prerequisite questions for the unit's check. Practice sets and tests for Unit 2 now draw from a much wider pool, so sets built across the unit deal fresh question shapes rather than the same shapes with new numbers.
- The follow-on sets after a pack's prerequisite check are now called Revisit sets (they were Repair sets).
- Three questions in the Math 2201 Unit 1 pack that only made sense with their answer choices in front of you have been replaced in the printed sets with questions that stand on their own on paper (the originals remain in the online bank, where the choices always show). One new question template was added to the bank for a mixed practice set. The pack's page footers now carry just the pack, course and unit names. Set codes are unchanged.

- The Math 2201 Unit 1 StudyMate pack was regenerated with print refinements from classroom review: working space is now plain white space with no ruled lines, diagrams sit at the left margin so the space beside them can be worked in, examples are headed "Example" and print without answer choices, and no question ever splits across a page. In a digital copy of the pack, each set's printed code and QR code are clickable links to that set. One Math 2201 question's wording was also clarified ("Which law should you use, and why?").
- The Math 2201 Unit 1 StudyMate pack's set pages were tidied: the line under each set title is now a short description of the set rather than instructions, and each set's questions now start at the top of the page, flowing around the set code and QR code at the top right instead of leaving that space empty (a worked example that carries a diagram still starts below the code block, at full width).
- The Math 2201 Unit 1 StudyMate pack's working space now adapts to the question: a written-answer question that prints with a diagram gets less blank working space (the diagram already shows the setup), and one without a diagram gets more, since the student draws the setup as well as solving.
- The same adaptation now covers the Math 2201 Unit 1 StudyMate pack's questions whose answer choices are withheld: one that prints with a diagram gets less blank working space, and one without a diagram gets more.
- The Math 2201 Unit 1 StudyMate pack no longer prints a worked example at the head of each indicator section: the examples read as a short set of notes rather than practice. The full worked solution for every question is in the online set, as the pack's answer keys already direct. No set's questions, order or codes changed.
- Fixed a Math 3208 Unit 1 question on evaluating a composite function where the second function printed as plain text instead of math notation, with a stray symbol after the first function. The question and its answer are unchanged; it now displays in full math notation.
- Fixed five Math 2200 Unit 4 solutions (converting radicals between entire and mixed form, simplifying radicals with operations, and rationalizing denominators) where a stray symbol printed after the final answer. The questions and their answers are unchanged; the solutions now display cleanly.
- Fixed the printed set code block not appearing on practice sheets and exams printed the ordinary way. The block (set code, QR code and the line explaining it) was only added for sets built in the advanced tools view, so a sheet or exam made the ordinary way printed with no code at all. It now appears on every printed sheet and exam with the option on, whichever way the set was made, and a set built from a seed word prints the same code every time it is opened.
- Fixed diagrams and photos going missing from downloaded Word files. A practice sheet or exam downloaded as a Word file now carries every diagram and photo from the set, at the size it appears in the app and rendered sharply for print. Before, the Word file held the words and equations only, and the pictures had to be copied over by hand.

## v1.2.0 - 2026-11-15

### Added

- Composed tests now spread their questions more evenly across a unit's outcomes. A composition can limit how many questions on one paper come from a single outcome, so one outcome no longer crowds a paper by chance. Science 7 unit tests use this now, and other courses can adopt it as their question banks are built.
- A course can now mark a question as practice only. Practice-only questions stay available in practice sets and for teachers to pick directly, and they stay out of composed tests and reviews. Science 7 uses this for its design-an-experiment question, which is written for practice rather than for a unit test paper.

## v1.1.0 - 2026-11-15

### Added

- The course picker now has a "What's new" link at the top. It opens these release notes, so you can follow improvements and changes to the apps as they land.
- No student information is collected by the apps' new usage counting. The apps now tally anonymous counts of which courses and features are used, so we can improve the ones teachers and students rely on. The counts never include names, answers, scores, or anything that identifies a student, a class, or a device, and a short note on the course picker explains this.

## v1.0.0 - 2026-11-15

### Added

- Practice now notices when a student needed support before answering. If a question is answered correctly after opening a hint, a worked example, or the worked solution, it still counts in the score, and it is also treated as an idea that needs more practice. It can return in the follow up practice set.
- Teacher tools are easier to read in dark mode. The panels used to edit questions, build papers, and build sheets now use a dark background in dark mode, so their headings, labels, and helper text stay clear.

## 2026-11-15

### Math 2201 prerequisite checks

- Math 2201 now has a short prerequisite check for each unit. A check uses skills students need before the unit starts, so a class can see what is solid before new work begins.
- At the end of a check, the summary names the skill groups in plain language and marks each one as solid or needing more practice.
- Choosing to practise what was missed now deals fresh questions from the missed skill groups only. Skills already shown as solid are left out.
- The Formulas and facts panel for the current unit no longer appears above a prerequisite check, since the check is about skills from earlier learning.
- One Unit 3 prerequisite question now stays with square roots. That matches the readiness students need before quadratic equations.

### Teacher choices for student links

- Teachers can now choose whether student links include hints. The choice sits beside the copy buttons in the teacher tools and stays set on the teacher's device.
- Teachers can also choose whether student links include worked examples.
- In a set that students check at the end, the worked example button now appears only after the set has been graded. If a teacher has turned worked examples off for a link, they stay off after grading.
- Worked solutions and answer keys are not changed by these choices.

### Focused retry practice

- When a student finishes a set that was checked at the end, then chooses to practise what was missed, the new practice set checks each question as the student goes. This gives a chance to correct mistakes right away.
- Teachers who prefer the first set's checking style can choose "Keep the first set's mode" for student links.
- A missed skill group made only of harder questions can now repeat with fresh versions until the retry set reaches its full size.
- If worked examples are turned off in a student link, the general hint no longer points students to a worked example they cannot open.

### Math 2200 prerequisite checks

- Math 2200 now has a short prerequisite check for each of its nine units, built the same way as the Math 2201 checks. Each check uses skills from earlier courses that the unit builds on.
- At the end of a check, the summary names the skill groups in plain language and marks each one as solid or needing more practice, and practising what was missed deals fresh questions from the missed skill groups only.
- Prerequisite check questions no longer appear in composed tests and exams for Math 2200. Teachers can still include them on purpose with the existing teacher choice.

## 2026-11-14

### Earth Systems 3209 added

- Earth Systems 3209 is now available in the course picker.
- The course includes questions from all five units, with practice sets and builders for course tests and exams.
- Earth Systems 3209 also appears in the Report a Problem form, so questions about it can be sent with the right course name attached.

### Practice can be picked up again

- If a student closes or reloads the page in the middle of a practice set, the app can offer to resume the same set on that device and browser. Answers, checks, and revealed help are restored.
- A practice exam in progress can also be resumed, with its timer continuing from the saved time.
- Saved work is kept for seven days. It stays in the student's browser and is not sent anywhere.
- On printed sheets and Word exports, each question number now sits on the same line as its question, so pages need less tidying before use.

### Fairer checking for longer written answers

- Longer written answers are no longer marked wrong just because they do not match a stored answer word for word.
- For these questions, checking opens the model answer and the marking points. Students compare their own answer and choose "I got it", "I got part of it", or "I missed it".
- Short answers with one clear correct form are still checked automatically.
- Printed sheets, Word exports, and answer keys are unchanged.

### Hints readable in dark mode

- Hints in dark mode are readable again. A hint box had kept a pale background while its text turned pale as well, which could make a hint look blank.
- Light mode hints look the same as before.

### Problem reports for every course

- The Report a Problem form is now called "CDLI Review Apps: Report a Problem".
- The form now lists every course in the apps, not only mathematics courses, so reports arrive with the right course attached.

## 2026-11-13

### A clearer CDLI look

- The official CDLI logo now appears on the course picker and on course pages. In dark mode, the white version of the logo is used so it stays clear.
- Printed practice sheets, exams, and answer keys now carry a small CDLI logo strip at the top of the first page.
- The Dark mode and Light mode choice on the picker is clearer, and a theme choice carries across courses more reliably.
- Course pages keep a teacher's saved theme choice when one exists.

Version note: Version numbers begin at v1.0.0 with the first tagged release. Changes before that release are listed by date above.
